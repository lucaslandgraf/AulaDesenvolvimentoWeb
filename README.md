# 💻 Desenvolvimento Web Básico - 2024.2

## 🎯 Objetivo da Disciplina
Este repositório contém o material de estudo, slides e códigos-fonte desenvolvidos nas aulas de **Desenvolvimento Web Básico**, focando nos pilares essenciais da web moderna:
1.  **Estrutura (HTML5)**
2.  **Estilização (CSS3) e Frameworks (Bootstrap)**
3.  **Comportamento e Interatividade (JavaScript e DOM)**

---
